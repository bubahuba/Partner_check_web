# Документация по конфиденциальности и разрешениям PartnerCheck

## Обзор

PartnerCheck — это приложение для проверки совместимости, которое помогает визуализировать и сравнивать контакты с помощью сопоставления на основе цветов. В этом документе объясняется, почему приложение запрашивает доступ к вашим контактам и как обрабатываются ваши данные.

## Почему мы запрашиваем доступ к контактам

PartnerCheck запрашивает доступ **только для чтения** к вашим контактам с одной конкретной целью:

### Только выбор контактов

Приложение использует нативный селектор контактов вашего устройства, чтобы позволить вам **вручную выбирать** контакты, которые вы хотите добавить в приложение. Мы **НЕ** получаем автоматический доступ, не читаем и не импортируем все ваши контакты. Вы полностью контролируете, какие контакты добавляются.

**Что происходит, когда вы предоставляете разрешение:**
- Приложение открывает стандартный селектор контактов вашего устройства
- Вы просматриваете и выбираете отдельные контакты самостоятельно
- Обрабатывается только контакт, который вы явно выбираете
- Приложение никогда не получает доступ к вашим контактам без вашего прямого действия

## Какие данные мы получаем

Когда вы выбираете контакт через селектор, приложение получает доступ к:

1. **Имя контакта** - Отображаемое имя выбранного контакта
2. **Номер телефона** - Первый номер телефона, связанный с контактом (если доступен)

## Какие данные мы сохраняем

Приложение сохраняет данные **только локально на вашем устройстве**. Мы сохраняем:

1. **Имя контакта** - Имя, которое вы выбрали
2. **Значение цвета** - Числовой цветовой код, полученный из номера телефона

**Важно:** Мы **НЕ** сохраняем:
- Фактический номер телефона
- Адреса электронной почты
- Адреса
- Любую другую контактную информацию
- Фотографии или изображения

## Как используются номера телефонов

Номер телефона используется **только** для генерации уникального цвета для визуального отображения:

1. Приложение извлекает последние 6 цифр из номера телефона
2. Эти цифры преобразуются в шестнадцатеричный цветовой код
3. Цвет используется для отображения контакта в приложении
4. **Сам номер телефона никогда не сохраняется** - сохраняется только результирующее значение цвета

Это означает:
- Каждый контакт получает уникальный, согласованный цвет на основе его номера телефона
- Цвет помогает визуализировать совместимость между контактами
- Исходный номер телефона отбрасывается после расчета цвета

## Хранение данных и конфиденциальность

### Только локальное хранилище

Все данные сохраняются **исключительно на вашем устройстве** с использованием локального хранилища (SharedPreferences). Это означает:

- ✅ Ваши данные никогда не покидают ваше устройство
- ✅ Данные не отправляются на серверы или третьим лицам
- ✅ Для основной функциональности не требуется подключение к Интернету
- ✅ Вы можете удалить все данные, удалив приложение

### Хранение данных

- Данные сохраняются на вашем устройстве до тех пор, пока вы вручную не удалите контакты или не удалите приложение
- Вы можете удалить отдельные контакты в любое время через интерфейс приложения
- Удаление приложения удаляет все сохраненные данные

## Объяснение разрешений

### Разрешение READ_CONTACTS

**Зачем нужно:** Чтобы открыть нативный селектор контактов, чтобы вы могли выбрать контакты для добавления.

**Что это позволяет:**
- Открывать интерфейс селектора контактов системы
- Читать только контакт, который вы явно выбираете
- Читать имя и номер телефона этого выбранного контакта

**Чего это НЕ позволяет:**
- Автоматически получать доступ ко всем контактам
- Читать контакты без вашего выбора
- Изменять или удалять контакты в вашей адресной книге
- Получать доступ к любой другой контактной информации помимо того, что вы выбираете

**Тип разрешения:** Только для чтения (мы запрашиваем `readonly: true`)

### Разрешение WRITE_CONTACTS

**Примечание:** Хотя это разрешение объявлено в манифесте Android для совместимости с библиотекой селектора контактов, **мы не записываем, не изменяем и не удаляем контакты в вашей адресной книге**. Приложение только читает контакт, который вы выбираете, и сохраняет минимальное количество данных локально.

## Ваши права и контроль

Вы полностью контролируете свои данные:

1. **Выберите, какие контакты добавить** - Обрабатываются только контакты, которые вы явно выбираете
2. **Удаляйте контакты в любое время** - Удаляйте любой контакт из приложения в любое время
3. **Отзовите разрешение** - Вы можете отозвать доступ к контактам в настройках устройства
4. **Опция ручного ввода** - Вы можете добавлять контакты вручную без использования селектора контактов
5. **Полное удаление данных** - Удаление приложения удаляет все сохраненные данные

## Безопасность и лучшие практики

- Вся обработка данных происходит локально на вашем устройстве
- Нет сетевой передачи контактных данных
- Нет обмена данными с третьими лицами
- Минимальный сбор данных (только имя и производное значение цвета)
- Доступ к контактам только для чтения

## Лимит контактов (бесплатная версия)

Бесплатная версия позволяет до 10 контактов. Этот лимит:
- Применяется только к контактам, хранящимся в приложении
- Не влияет на список контактов вашего устройства
- Не ограничивает вашу способность использовать контакты в других местах
- Может быть обновлен путем покупки PartnerCheck Pro для неограниченного количества контактов

## Часто задаваемые вопросы

**В: Приложение получает доступ ко всем моим контактам?**  
О: Нет. Приложение получает доступ только к контактам, которые вы явно выбираете через селектор контактов.

**В: Отправляются ли мои контактные данные на серверы?**  
О: Нет. Все данные остаются на вашем устройстве. Контактная информация не передается через Интернет.

**В: Может ли приложение изменять мои контакты?**  
О: Нет. Приложение имеет доступ только для чтения и не изменяет, не удаляет и не добавляет контакты в вашу адресную книгу.

**В: Что происходит, если я отзываю разрешение на контакты?**  
О: Вы все еще можете использовать приложение, добавляя контакты вручную. Функция селектора контактов будет недоступна, пока вы снова не предоставите разрешение.

**В: Как используется мой номер телефона?**  
О: Номер телефона используется только для расчета цветового кода. Фактический номер телефона никогда не сохраняется - сохраняется только результирующее значение цвета.

**В: Могу ли я использовать приложение, не предоставляя разрешение на контакты?**  
О: Да. Вы можете добавлять контакты вручную, вводя имя и номер телефона самостоятельно.
